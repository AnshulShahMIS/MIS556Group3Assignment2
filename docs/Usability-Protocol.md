# Career Compass student usability protocol

## Purpose
Test whether students can complete the core journey and understand the limitations. No participants or results are claimed yet. Recruit 3–5 consenting classmates or students; use fictional or redacted data and follow any applicable course requirements.

## Procedure
Give each participant a fictional resume and job description. Ask them to think aloud while they: (1) enter the inputs, (2) identify one supported skill and one uncertain requirement, (3) inspect the source evidence, (4) improve one bullet without inventing facts, (5) set a weekly budget and select a plan milestone, (6) answer one interview question, and (7) save and reopen a session. Do not coach them through the interface unless they are stuck; record where assistance was needed.

## Questions after the tasks
- Which recommendation was most useful, and why?
- Which result was unclear or incorrect?
- What does the coverage percentage mean? Does it establish proficiency or hiring likelihood?
- Can you find the evidence and source behind a recommendation?
- Did any suggestion invent or overstate your experience?
- Would you use this alongside campus career services? What would need to improve first?

Use 1–5 ratings for clarity, usefulness and trust calibration, plus an explanation for each. Ratings are descriptive feedback from a small convenience sample, not statistically representative findings.

## Synthesis
Report the actual number of participants, dates, common difficulties, observed task completion and resulting changes. Separate observations from interpretations. Do not claim improved job outcomes. Repeat failed tasks after fixes. After AI is connected, include a task that checks the relevance of a generated citation and the response to insufficient evidence.
